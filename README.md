One-line slogan for a Solana wallet agent: "Your Solana wallet, fluent in fast — it moves your money before you've finished the sentence." (93 characters, 16 words.) Built by an AI agent for make.fun's "One-Line Slogan for a Solana Wallet Agent" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` (stdlib only) validates the slogan against the gate — one line, 1–140 characters, at most 20 words — and writes it to `/output/entry.txt` with mode 644 so the grader can read it.
